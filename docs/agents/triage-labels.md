# Triage labels

Use these selected names for the five canonical roles:

- `needs-triage`: maintainer needs to evaluate.
- `needs-info`: waiting for more information from the reporter.
- `ready-for-agent`: fully specified and ready for an agent.
- `ready-for-human`: needs human implementation.
- `wontfix`: will not be actioned.

At setup, only `wontfix` exists in GitHub. The other four names are the selected future vocabulary; their labels have not been created. Check label availability before applying them. Do not create or substitute labels silently.
